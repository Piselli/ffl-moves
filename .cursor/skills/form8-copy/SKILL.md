# FORM8 copy

Use with project skills `copywriting` and `copy-editing` for craft; this file is
the **brand voice + product rules**.

## Voice

- Sports-tech, short, confident. Not hype, not startup-brochure.
- UA/EN: match the surface language; don't mix in one block.
- Prefer nouns users already use: Code, Creative, Fee vol, Sign in.

## Hard rules

1. **No tip essays.** No `Code — explanation` bullets. Prefer path + one line, or numbered steps.
2. **Delete microcopy the user rejects.** Don't rephrase the same clutter.
3. **Buttons = verb + object** when needed (`Create code`, `Sign in`, `Copy`) — not `Submit` / `OK`.
4. **Errors = what happened + what to do.** Calm. No blame.
5. **Don't explain the brand green or the glass.** Show, don't narrate chrome.
6. **Partner cabinet:** "Partners cabinet", not "Partner Access Portal" / "Unlock your dashboard".

## Density

| Surface | Copy budget |
|---------|-------------|
| Section label | 1–3 words |
| Help rail | ≤3 short blocks |
| Modal body | 1 sentence max under title |
| Empty state | 1 sentence + 1 action |

## Anti-slop phrases (ban)

seamless, powerful, next-gen, unlock, elevate, journey, leverage, dive in, get started on your, welcome to the future
