Matchday Gate — три найкращі композиції

Холодна людина з Instagram: 1 секунда на рішення. Нижче три різні ієрархії, не три кольори. Фон скрізь — реальний локер (бренд). Обери один — далі кодим.

Задача екрана: продати тап на «Зібрати команду».
Має бути видно: пул (гроші) · менеджери (люди вже всередині) · Game Week + Open/Closed (час).
Не задача: пояснювати крипту, правила, топ-10.
