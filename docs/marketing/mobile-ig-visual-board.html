Твій вибір

Натисни варіант вище або тут. Можна також гібрид: наприклад A структура + B атмосфера на entry.

Поки не обрано — моя робоча рекомендація: A для реклами, з легким locker-strip з B якщо захочеться бренду.

Що далі після вибору

  1. Lock reference (tokens + copy + screen order).
  2. P0 у коді: email-first login, WebView→Safari, deposit без «USDC» у Cash.
  3. P1: mobile entry + pick defaults за обраним варіантом.
